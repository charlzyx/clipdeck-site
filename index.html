已有项目访问权限？

可从项目源码在 Mac 上构建。需要 Swift 6 工具链；安装后在应用设置中检查权限。

查看 GitHub 项目 ↗当前项目为私有仓库，需要访问权限。
源码构建与安装步骤
  1. 获取源码，进入项目目录。
  2. 构建应用：bash scripts/build.sh
  3. 安装应用：bash scripts/install.sh
  4. 从「应用程序」打开 ClipDeck，在设置中检查辅助功能与屏幕录制权限。

自动粘贴需要辅助功能授权，截图需要屏幕录制授权。默认构建使用 ad-hoc 签名。
