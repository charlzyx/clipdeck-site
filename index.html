安装、校验与权限
  1. 下载 ZIP 和校验文件，放在同一目录。
  2. 在终端进入下载目录，运行 shasum -a 256 -c ClipDeck-0.3.5-macos-arm64.zip.sha256，确认显示 OK。
  3. 解压 ZIP，将 ClipDeck.app 拖入「应用程序」。
  4. 打开 ClipDeck，在应用设置中检查权限。自动粘贴需要辅助功能授权，截图需要屏幕录制授权。

此版本未提供 Developer ID 签名与 Apple 公证。Intel Mac 安装包暂未提供。
